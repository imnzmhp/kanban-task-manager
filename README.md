# Kanban Task Manager

React + TypeScript + Viteで構築されたモダンなカンバンタスク管理システムです。美しいUI/UX、レスポンシブデザイン、そして堅牢なデータ永続化機能を提供します。

## 🚀 機能

### ✨ コア機能
- **ドラッグ&ドロップ**: タスクを直感的にカラム間で移動
- **リアルタイムデータ永続化**: ブラウザのLocal Storageを使用した自動保存
- **完全レスポンシブ**: デスクトップ・タブレット・モバイル対応
- **アクセシビリティ**: WCAG準拠のバリアフリー設計

### 🎨 UI/UX
- **モダンデザイン**: CSS Modulesによる美しいビジュアル
- **ダークモード**: システム設定に応じた自動切り替え
- **アニメーション**: 滑らかなトランジション効果
- **Toast通知**: 操作フィードバックとエラーハンドリング

### 📱 レスポンシブデザイン
- **モバイルファースト**: 480px以下でのモバイル最適化
- **タブレット対応**: 768px以下でのレイアウト調整
- **デスクトップ**: フル機能のワイドスクリーン対応

## 🎯 使用方法

### 基本操作
1. **新しいタスクを作成**: 各カラムの「+」ボタンをクリック
2. **タスクを移動**: タスクカードをドラッグして他のカラムにドロップ
3. **タスクを編集**: タスクカード上の編集ボタンをクリック
4. **タスクを削除**: 削除ボタンをクリックして確認

### カラム構成
- **TODO**: 新しいタスク・未着手のタスク
- **DOING**: 作業中のタスク
- **DONE**: 完了したタスク

## 🏢 本番での使用方法

### エンドユーザー向け操作ガイド

#### 🆕 タスクの作成
1. **新規タスク追加**
   - 各カラム（TODO/DOING/DONE）の上部にある「+ 新しいタスクを追加」ボタンをクリック
   - タスクフォームが表示されます

2. **タスク情報の入力**
   - **タイトル**: 必須項目（1-200文字）
   - **説明**: オプション（最大1000文字）
   - 「保存」ボタンで作成完了

#### ✏️ タスクの編集・管理
1. **タスクの編集**
   - タスクカード右上の「編集」ボタン（鉛筆アイコン）をクリック
   - タイトルや説明を変更して「更新」ボタンで保存

2. **タスクの移動**
   - **ドラッグ&ドロップ**: タスクカードをクリックして他のカラムにドラッグ
   - **モバイル**: タスクカードをタップして移動先カラムを選択

3. **タスクの削除**
   - タスクカード右上の「削除」ボタン（ゴミ箱アイコン）をクリック
   - 確認ダイアログで「削除」を選択

#### 🔄 ワークフロー管理
1. **推奨作業フロー**
   ```
   新規タスク → TODO → DOING → DONE
   ```

2. **プロジェクト管理のベストプラクティス**
   - **TODO**: 計画段階、要件定義、バックログ
   - **DOING**: 作業中、進行中タスクは3-5個以内に制限
   - **DONE**: 完了したタスク、レビュー済みタスク

#### 📊 プロジェクト進捗の確認
1. **ボード統計の確認**
   - 画面上部に各カラムのタスク数と合計が表示
   - リアルタイムでプロジェクト進捗を把握可能

2. **タスクの優先順位管理**
   - カラム内でのドラッグ&ドロップによる順序変更
   - 重要なタスクを上位に配置

### 💾 データ管理

#### 自動保存機能
- **即座に保存**: 全ての操作（作成・編集・移動・削除）が自動的に保存
- **ブラウザ再起動対応**: ページを閉じても次回起動時にデータが復元
- **データ同期**: 同一ブラウザ内であれば複数タブでデータ共有

#### データのバックアップ・移行
1. **データのエクスポート**（将来実装予定）
   ```bash
   # ブラウザの開発者ツールで実行
   localStorage.getItem('kanban-tasks')
   ```

2. **データの復元**
   - ブラウザのLocal Storageにデータが自動保存
   - 同じブラウザ・同じドメインでアクセスすれば自動復元

### 🖥️ デバイス別の使用方法

#### 💻 デスクトップ
- **マウス操作**: フルドラッグ&ドロップ機能
- **キーボードショートカット**: Tab, Enter, Escapeキーでナビゲーション
- **大画面表示**: 3カラムを同時表示

#### 📱 モバイル・タブレット
- **タッチ操作**: タップとスワイプでタスク管理
- **レスポンシブ表示**: 画面幅に応じたレイアウト調整
- **縦画面対応**: カラムが縦に積み重なる表示

### ⚠️ 制限事項と注意点

#### データ保存の制限
- **Local Storage使用**: データはブラウザ固有（他のブラウザ・デバイスと共有不可）
- **同一ドメイン限定**: 同じURL（ドメイン・ポート）でのみデータ共有
- **ストレージ容量**: 通常5-10MB程度の制限（数千タスクまで対応可能）
- **プライベートモード**: ブラウザのプライベートモードではデータが保持されない場合があります

#### データが共有されない場合
- ❌ **異なるデバイス**: PC ↔ スマートフォン ↔ タブレット
- ❌ **異なるブラウザ**: Chrome ↔ Firefox ↔ Safari
- ❌ **異なるドメイン**: localhost:5173 ↔ localhost:5174
- ❌ **プライベートモード**: 通常モード ↔ シークレットモード

#### データ移行の方法
1. **手動エクスポート/インポート**（将来実装予定）
   - JSONファイルでのデータバックアップ
   - 異なるブラウザ・デバイス間でのデータ移行

2. **URL共有**（将来実装予定）
   - 少数のタスクをURL経由で共有
   - 一時的なデータ共有に便利

#### 推奨使用環境
- **ネットワーク**: オフラインでも使用可能（初回読み込み後）
- **JavaScript必須**: JavaScriptが無効な環境では動作しません
- **現代的ブラウザ**: Internet Explorer非対応

### 🔧 トラブルシューティング

#### よくある問題と解決方法
1. **タスクが表示されない**
   - ブラウザを再読み込み（F5またはCtrl+R）
   - ブラウザのLocal Storageが有効か確認

2. **ドラッグ&ドロップが機能しない**
   - **React Strict Mode問題**: React 18のStrictModeが無効化されていることを確認
   - **ブラウザ互換性**: モダンブラウザ（Chrome 88+, Firefox 78+, Safari 14+）を使用
   - **JavaScript有効**: JavaScriptが有効になっていることを確認
   - **マウス操作**: マウスでクリック&ドラッグを確認
   - **モバイル**: タップ&ホールド操作を試行（長押し後ドラッグ）

3. **データが消失した**
   - 同じブラウザ・同じドメインでアクセスしているか確認
   - ブラウザの履歴やキャッシュクリアの影響を確認

#### エラー通知の対応
- 画面右上にToast通知が表示された場合の対処法
- **赤色（エラー）**: 操作を再試行または内容を確認
- **黄色（警告）**: 推奨されないが継続可能な状況
- **緑色（成功）**: 操作が正常完了
- **青色（情報）**: 追加情報やヒント

## 🏗 アーキテクチャ

### フォルダ構成
```
src/
├── components/          # Reactコンポーネント
│   ├── AppInitializer.tsx    # アプリ初期化
│   ├── KanbanBoard.tsx       # メインボード
│   ├── Column.tsx            # カラムコンポーネント
│   ├── TaskCard.tsx          # タスクカード
│   ├── TaskForm.tsx          # タスクフォーム
│   ├── Toast.tsx             # 通知システム
│   └── ErrorBoundary.tsx     # エラーハンドリング
├── contexts/            # React Context (状態管理)
│   ├── TaskContext.tsx       # タスク状態管理
│   ├── ToastContext.tsx      # Toast通知管理
│   └── AppProviders.tsx      # プロバイダー統合
├── hooks/              # カスタムフック
│   ├── useTask.ts           # タスク操作フック
│   ├── useToast.ts          # Toast操作フック
│   └── usePersistence.ts    # データ永続化フック
├── services/           # ビジネスロジック
│   ├── TaskRepository.ts     # タスクデータ管理
│   └── LocalStorageService.ts # ストレージ操作
├── types/             # TypeScript型定義
│   ├── Task.ts              # タスク関連型
│   └── Toast.ts             # Toast関連型
└── utils/             # ユーティリティ関数
    └── taskUtils.ts         # タスク操作ヘルパー
```
